# НИНА ПРИНЕСЛА новый НОУТ

Журнал подсказок по установке Windows на новый ноутбук. Все ответы Claude дублируются сюда автоматически.

---

## Шаг 0. Что нужно выяснить перед началом

Чтобы дать точную инструкцию, нужны ответы на вопросы:

1. **Что сейчас на ноуте?** Пустой диск / предустановлена Windows (какая, с лицензией?) / Linux / FreeDOS.
2. **Модель ноутбука** (наклейка снизу или на коробке). От этого зависят драйверы и способ входа в BIOS.
3. **Какую Windows ставить?** Рекомендация: Windows 11 Pro или Home (ноут 2024-2026 года почти наверняка её поддерживает). Windows 10 уже без поддержки с октября 2025.
4. **Есть ли лицензия?** Ключ от старого ПК (Retail можно перенести, OEM нельзя) или покупать новый. Можно ставить без ключа и активировать позже.
5. **Есть ли флешка от 8 ГБ** и второй компьютер с Windows (этот), чтобы её подготовить.
6. **Есть ли проводной интернет или Wi-Fi** рядом с ноутом (установщик Win11 требует сеть и аккаунт Microsoft, но это можно обойти).

---

## Шаг 1. Готовим загрузочную флешку (делается на этом ПК)

1. Скачать **Media Creation Tool** для Windows 11: https://www.microsoft.com/software-download/windows11
2. Вставить флешку (всё на ней будет стёрто).
3. Запустить `MediaCreationTool.exe` → «Создать установочный носитель» → язык «Русский», выпуск «Windows 11», архитектура 64-bit → «USB-устройство флэш-памяти» → выбрать флешку → ждать 10-30 минут.

Альтернатива (если нужно обойти требования TPM/аккаунт Microsoft): скачать ISO с того же сайта и записать через **Rufus** (https://rufus.ie), в окне после нажатия «Старт» поставить галочки «Удалить требования 4GB+ RAM, Secure Boot и TPM 2.0» и «Удалить требование онлайн-аккаунта Microsoft».

---

## Шаг 2. Загрузка с флешки на ноуте

1. Воткнуть флешку в выключенный ноут.
2. Включить и сразу многократно нажимать клавишу выбора загрузки:
   - ASUS: `Esc` или `F8`
   - Acer: `F12` (может потребоваться включить F12 Boot Menu в BIOS через `F2`)
   - Lenovo: `F12` или кнопка Novo (маленькая дырочка сбоку)
   - HP: `Esc`, затем `F9`
   - Dell: `F12`
   - MSI: `F11`
   - Huawei/Honor: `F12`
3. В меню выбрать пункт с «UEFI: <имя флешки>».
4. Если флешка не видна: зайти в BIOS (`F2`/`Del`), отключить **Secure Boot**, включить режим загрузки **UEFI**, сохранить (`F10`).

---

## Шаг 3. Установка

1. Язык → «Установить» → «У меня нет ключа продукта» (если ключа нет) → выбрать выпуск (Home или Pro).
2. «Выборочная установка».
3. На экране дисков: если диск пустой — выбрать «Незанятое пространство» → «Далее». Если есть старые разделы и данные не нужны — удалить все разделы по очереди, затем выбрать незанятое пространство.
4. Копирование файлов 10-20 минут, перезагрузка. **Вытащить флешку** при первой перезагрузке.
5. Первичная настройка (OOBE): регион, раскладка, Wi-Fi.
6. **Обход аккаунта Microsoft** (если хочется локальный аккаунт): на экране «Подключимся к сети» нажать `Shift+F10`, в чёрном окне ввести:
   ```
   start ms-cxh:localonly
   ```
   Появится окно создания локального пользователя. (На старых сборках вместо этого работало `oobe\bypassnro` и перезагрузка.)

---

## Шаг 4. После установки

1. Подключить интернет → Параметры → Центр обновления Windows → проверить обновления, повторить несколько раз до «Вы в курсе последних событий». Большая часть драйверов приедет сама.
2. Зайти на сайт производителя ноута → поддержка → ввести модель → скачать драйверы: чипсет, видео, Wi-Fi/Bluetooth, тачпад, аудио, а также фирменную утилиту (MyASUS, Lenovo Vantage, HP Support Assistant и т.п.).
3. Активация: Параметры → Система → Активация → ввести ключ.
4. Поставить браузер, архиватор (7-Zip), офис, антивирус не обязателен — Defender достаточно.
5. Проверить: диспетчер устройств без жёлтых восклицательных знаков, работает звук, камера, тачпад, яркость, Wi-Fi.
